# Meow - 打字时可以在句尾加喵的程序喵

可以在句尾添加后缀，替换文本。主要方便用户进行卖萌  
~~可以轻松打破人与猫娘语言之间的隔阂，削弱部分人扮演中的羞耻感（~~

## 功能
### 触发模式
- 回车触发模式：当用户按下Enter键时进行操作
- 标点实时触发模式：当用户输入指定标点时进行操作
- 快捷键触发模式：当用户按下指定快捷键时进行操作
### 基础选项
- 后缀去重：检测到有相同后缀时不会添加后缀
- 单字语气词跳过：当检测到单独成段的单个语气词时不会添加后缀
### 设置功能
- 判定设置：可以设置内置的标点、语气词和屏蔽词
- 文字替换：可以设置将指定词进行替换。可以用于改变句子语气，语言习惯等

## 命令行参数

| 参数 | 作用 |
|------|------|
| `--debug` | 开启调试控制台 |
| `--top` | 窗口置顶 |
| `--discard` | 不保存配置 |
